## Tips Penggunaan

1. **Midjourney**: Tambahkan `--style raw --ar 1:1` di akhir prompt untuk icon, `--ar 3:4` untuk full body
2. **DALL-E**: Prompt bisa dipakai langsung
3. **Stable Diffusion**: Tambahkan `masterpiece, best quality` di awal dan `(worst quality:1.4)` di negative prompt
4. **Konsistensi**: Generate character sheet dulu, lalu gunakan sebagai reference untuk variasi mode
5. **Format output**: Minta PNG dengan transparent background untuk integrasi ke app
